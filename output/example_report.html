Re7 social insights: collect → analyse → create

Case study Part 1, Marketing Automation · Benjamin Vornique · data snapshot 28 October 2026 · code: re7_social_insights.zip

1. The workflow

1 · CollectX API v2 (public_metrics) for @Re7Capital and @Re7Labs · LinkedIn Page analytics CSV export · Telegram public preview (t.me/s/…) · re7.capital/blog as source content. One table: posts.csv (channel, account, date, format, text, url, impressions, engagements).
2 · Analyse (AI)Claude tags each post with one of 7 themes (Weekly, TradFi interviews, research, events, vault/yield, company, other). The script ranks themes and formats per channel by median engagements and engagement rate → insights.json.
3 · Create (AI)Claude drafts an X thread, a LinkedIn post and a Telegram note from the latest Weekly and research, steered by the winning themes/formats, with channel rules and a facts-only, no-advice constraint → drafts.json.

python run.py --live runs all three steps; python run.py replays the snapshot below. It runs weekly after The Weekly is published (cron / GitHub Actions). Drafts go to the team for review and are never posted automatically. Without an API key, rule-based fallbacks keep it running end to end.

3. Insights

  • LinkedIn rewards substance in native formats. The research report (document) got about 4× the engagement of a Weekly link post. Interview clips come second. The Weekly, Re7's most regular content, performs worst because it ships as a bare link.
  • X @Re7Capital has a reach problem, not a content problem. Non-pinned posts get only 250–400 views, but interviews and the Weekly convert at over 1%. Better packaging (native threads, a number in the hook, the link in the last post) should lift reach.
  • X @Re7Labs: partners bring reach, numbers bring engagement. Co-tagged launches (Kamino/Plume, Frax/USDai) reach 9k–29k views. Plain APY posts reach about 1k but engage 5× better.
  • Events are high effort for low return as stand-alone “will be speaking” posts (median 9). Recap clips and takeaways after the event are the better use.

6. Method and limits

  • Data. 22 posts from the last 3–7 weeks, collected on 28 Oct 2026 from public pages (X status pages, the LinkedIn company feed, t.me previews). LinkedIn impressions are not public. In production they come from the admin CSV export, which unlocks engagement rates there too.
  • Sample size. Several theme groups have only 1–3 posts, so the rankings are directional. Run weekly, the pipeline builds a longer history, and the medians become reliable after about 8–10 weeks.
  • AI steps. Theme tagging and drafting call Claude (RE7_MODEL, default claude-sonnet-4-5). The prompt only allows facts present in Re7's sources and forbids investment advice and price predictions. A human review step is built in before anything is posted.
  • Setup. pip install -r requirements.txt; set ANTHROPIC_API_KEY and X_BEARER_TOKEN; drop the LinkedIn export in data/; run python run.py --live. See the README for details.
